# uPedal update channel

This repository only serves the signed APT repository from which uPedal
appliances look for newer releases. It is published with GitHub Pages at
https://diamondsea11.github.io/upedal-updates/apt.

- Every release is signed with the owner key
  `56D2D86B17211B61452AF7D2448BC8F4AD3C0A25` (diamondsea11). An appliance
  refuses anything else.
- An appliance only notifies; it installs a release only after the player
  confirms it in Settings -> System -> Software Update.
- Nothing is published here yet.
